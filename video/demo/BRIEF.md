# rederive demo film: brief

**Spec:** `1920x1080@60, 28s, 120BPM, audio: synthesized` (score plus UI effects, -14 LUFS). Plus a 9:16 (1080x1920, feed9x16 safe zones) and a 1:1 (1080x1080) re-layout from the same timeline. Built at xhigh effort (cinetic Step 0).

- Product: rederive, an open source skill for coding agents. It teaches a codebase by making the user design it: it poses the problem a part of the code solves, the user proposes a design, a real constraint breaks it, the user revises, and when the revision matches the real design the tool names it.
- Repo on screen: Linphone, the open source VoIP phone. The decision shown: how two phones behind home routers get voice packets to each other (ICE: a server swaps public addresses, then both sides send at once and go direct).
- Who it is for: engineers on X and Instagram, muted in a feed first.
- Direction from Eric (2026-10-20): white background, animated, speech bubbles, in the manner of the Muse launch video (flat white, redrawn UI, captions that pop in next to the thing they describe, one canvas the camera moves over, light upbeat bed). No interview hook. No terminal. It must look exciting: things move, the design is drawn live and breaks visibly.
- The previous film (video/launch) was dark, small and static; this one replaces it.
- End card practical fact: `github.com/EricJujianZou/rederive`, readable at least 1.7 s.
- Engine: Remotion 4.0.529, node_modules linked from video/launch.

## Brand supplied
- Mark: the ∂ glyph in assets/logo.png, traced in src/brand/Mark.tsx. It is cursive by nature; the italic ban does not apply to it (`cinetic:brand-supplied mark`).
- Wordmark: lowercase "rederive" in Geist (assets/banner-light.png).
- Stage: light this time. Ink #0D1117 from the brand, paper white, GitHub's light-theme green #1A7F37 as the one accent, meaning "resolved: your design matches the real one".

## Hard bans (from cinetic; critics check these word for word)
- Words: eyebrow or kicker labels; stacked taglines; "Introducing"; text walls; filler text, decorative mono captions, fake metrics, lorem ipsum.
- Type: serif; italic or oblique (except the supplied ∂ mark). One sans (Geist) plus a mono only for the install line.
- Colour: orange, amber, beige, cream, tan, sand; neon, glows, bloom, halos; purple, violet, indigo; multi-hue gradients; glassmorphism.
- Decoration: emoji and stock icons; sparkles for "AI", particles, confetti, lens flares, code rain; bouncy overshoot on anything that is not landing.
- Eric's writing bans apply to every on-screen word: no parallel sentence pairs, no clipped dramatic fragments, no tagline pairs, no triples, no em dashes, subject first.
